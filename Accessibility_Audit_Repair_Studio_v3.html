What this checker does

  • Checks HTML, ARIA, keyboard clues, forms, embedded CSS contrast, responsive overflow, and touch targets.
  • Ranks fixes from Nice to fix to Critical.
  • Provides targeted correction guidance and affected elements.
  • Shows which of the 20 manual-review areas were partially screened automatically.
  • Preview, approve, and export targeted repairs. Re-audit the patched HTML.

Choose a file to begin.

Scope: This is a source and safe-render preview checker, not an ADA certification tool. Uploaded JavaScript is disabled during audits; optional interaction testing runs inline scripts only in a separately isolated sandbox. A script-disabled sandbox preview checks embedded styles at two widths; external assets are blocked, so rendered findings are estimates. The screen-reader approximation is not NVDA, JAWS, or VoiceOver, and synthetic keyboard actions are not real Tab-key navigation. External stylesheets, linked documents, full application behavior and WCAG conformance still need real-world testing. All analysis and repairs happen in your browser; your file is not uploaded to a server. Repairs can modify page markup and appearance, so retest the running application.

    Not a legal compliance determination

    An integrated accessible table or keyboard interface may improve the same application. A separate conforming alternate version is legally restricted as a substitute for inaccessible primary content under the U.S. public-entity Title II rule (28 CFR § 35.202): direct accessibility must be impossible due to technical or legal limitations. Record evidence; do not automatically erase WCAG findings.
