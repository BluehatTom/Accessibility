What this checker does

  • Detects common HTML, ARIA, forms, image, navigation, and markup problems.
  • Ranks fixes from Nice to fix to Critical.
  • Provides targeted correction guidance and affected elements.
  • Adds manual tests for keyboard use, screen readers, contrast, video, and interactive features.

Choose a file to begin.

Scope: This is a static HTML checker, not an ADA certification tool. Uploaded scripts are never executed. External stylesheets, linked documents, runtime behavior, and full WCAG conformance require additional testing. All analysis happens in your browser; your file is not uploaded to a server.
